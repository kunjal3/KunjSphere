# KunjSphere 🌌 – Personal Learning Universe

**KunjSphere** is a personal dashboard web application designed to help students **organize tasks, track progress, schedule tests, and manage notices** — all in one place. It’s a **dark-themed, modern, responsive SPA-style interface** built using **HTML, Tailwind CSS, and JavaScript**, with **persistent storage using localStorage**.

---

## 🔹 Features

### 1. Dashboard
- Central overview of learning activities
- Displays:
  - Total tasks
  - Completed tasks
  - Pending tasks
  - Upcoming tests
  - Learning progress (visual progress bar)

### 2. Task Management
- Add and track daily tasks
- Mark tasks as completed
- Automatically updates progress
- Persistent storage using localStorage

### 3. Learning Section
- View completed tasks
- Acts as a learning history for revision

### 4. Notice Board
- Add, view, and manage personal notices
- Notices are stored in localStorage
- Can be used for reminders, exam schedules, study tips, or announcements

### 5. Assessments
- Schedule upcoming tests
- Mark tests as completed
- Shows upcoming tests on the dashboard
- Automatic progress updates

### 6. Progress Tracking
- Calculates task completion percentage in real-time
- Updates the progress bar dynamically

### 7. Settings
- Reset all data (tasks, notices, tests)
- Start fresh anytime

### 8. Dark Theme UI
- Modern dark blue and black color palette
- Tailwind CSS for fast and responsive design
- Eye-friendly interface similar to professional SaaS dashboards

## 🔹 How It Works

1. **Add Tasks:**  
   Users can add tasks and mark them completed. The dashboard shows progress automatically.

2. **Schedule Tests:**  
   Users can enter upcoming assessments, mark them as done, and track them on the dashboard.

3. **Manage Notices:**  
   Users can add personal notices/reminders that persist across sessions.

4. **Track Progress:**  
   The progress bar updates dynamically based on completed tasks.

5. **Reset Data:**  
   Users can reset all stored data anytime from the Settings tab.
